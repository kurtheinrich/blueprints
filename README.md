# Blueprints

Open-sourcing the architecture, not the code.

Each blueprint covers a tool I've built and use daily. Instead of publishing repos, I'm sharing the architecture, the decisions, and enough to rebuild it yourself with an AI coding agent.

Each blueprint includes:

- **README** — what it solves and why it exists
- **architecture.md** — how it's structured and key design decisions
- **prompt.md** — starter prompts to build your own version with an AI coding agent
