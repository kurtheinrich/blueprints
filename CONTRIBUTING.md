# Contributing

This is a reference repository - architecture docs and starter prompts for building your own versions of these tools with AI coding agents.

It's not accepting contributions, issues, or pull requests. The blueprints reflect how I actually use these tools, and I update them as the tools evolve.

If you build something from a blueprint, I'd love to hear about it - reach out via [kurtheinrich.com/contact](https://kurtheinrich.com/contact).
